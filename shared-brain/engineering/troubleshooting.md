# Shared Brain — Troubleshooting

Verified, reusable, cross-project troubleshooting procedures organized by symptom. Each entry
uses the knowledge template (`../templates/knowledge-template.md`). Add an entry only after the
procedure is verified and is reusable beyond one client.

## Entry template

```
### SB-TRB-###: <symptom-oriented title>
- **Category:** troubleshooting
- **Symptom:** <observable symptom>
- **Procedure:** <verified diagnostic / resolution steps>
- **Scope:** <technologies/contexts where it applies>
- **Evidence:** <logs / source / validation>
- **Source project / task:** <project-key> / <task-id>
- **Verification date:** YYYY-MM-DD
- **Applicable version / branch:** <if known>
- **Confidence:** high | medium | low
- **Invalidation conditions:** <what would make this obsolete>
- **Superseded-by:** <id or n/a>
```
